# Takano Hiroki ポートフォリオ

Next.js App Router、TypeScript、Tailwind CSS、Framer Motion、lucide-react で作成した個人ポートフォリオ兼制作物紹介サイトです。

## コマンド

```bash
npm install
npm run dev
npm run build
```

## デプロイ

AWS Amplify Hosting で公開する前提の設定を `amplify.yml` に含めています。

詳しくは [docs/deployment.md](docs/deployment.md) を参照してください。
